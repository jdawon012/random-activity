\# 🎲 오늘 뭐 하지?



사용자가 선택한 조건에 따라 오늘 할 활동을 랜덤으로 추천해주는 간단한 웹 애플리케이션입니다.



\## ✨ 주요 기능



\- 랜덤 활동 추천

\- 혼자 / 친구와 선택

\- 실내 / 실외 선택

\- 무료 / 유료 선택

\- 선택한 조건에 맞는 활동 필터링

\- 조건에 맞는 활동이 없는 경우 안내 메시지 표시



\## 🛠 사용 기술



\- HTML

\- CSS

\- JavaScript
